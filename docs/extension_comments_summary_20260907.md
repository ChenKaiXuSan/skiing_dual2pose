## 2. E4 补充的角度统计分析

对应问题分为两层，不能混在一起解释：

1. 在每个角度区间内，融合是否优于 canonical averaging？
   - 先按无序相机对聚合四个动作样本，避免将同一相机几何下的样本都当作独立重复。
   - 计算相机对 bootstrap 的 95% 置信区间。
   - 进行配对 Wilcoxon 检验，对六个检验作 Holm 校正，并报告秩二列相关效应量。
   - 六个区间的校正后 p 均小于 0.001，融合收益的置信区间均为正。

2. 不同角度区间的融合收益是否不同？
   - Kruskal–Wallis 检验 p=0.0251，但效应量 ε²=0.00049，非常小。
   - 15 组事后比较中，Holm 校正后仅 90–120° 与 150–180° 显著，p=0.0064，效应量 r_rb=0.053，同样很小。
   - 可写“各角度区间内均有可靠的融合收益，角度对收益幅度的影响很小”；不能写成“角度间完全没有差异”或“120–150° 是最佳部署角度”。

证据：[主文统计段落](../paper/ivc_draft_20260821/main.tex)、[主文角度表](../paper/ivc_draft_20260821/tables/view_angle_combined.tex)、[补充统计表](../paper/ivc_draft_20260821/tables/view_angle_significance.tex)。

## 3. E5 新增的图像级遮挡实验

原实验直接在姿态坐标上模拟损坏；新增实验把干预提前到图像端：

RGB 图像遮挡 → SAM3D 估计姿态 → 固定 CanonFuse3D → 与 canonical averaging 比较。

- 影响视角：left、right、both，三种。
- 遮挡模式：random、distal、temporal，三种。
- 比率：0.5、1.0，两档。
- 共 3×3×2=18 个条件，每个条件评估全部 64,440 个 Unity 测试相机对序列。
- 同时记录 SAM3D 人体检测失败率；失败输入以零姿态保留，未从评估中删除。
- 用 Unity 的投影标注放置遮挡块；这些标注不是姿态估计器或融合模型的输入。

主要结果：18 个条件中 15 个优于平均融合。random、ratio=1.0 时，左侧、右侧及双侧遮挡分别比平均融合差 18.0%、9.2%、28.4%。因此，新增证据同时说明图像误差经前端传播后仍有可用的融合收益，也说明严重遮挡下一路清晰视角并不保证融合优于平均。

图像级 ratio 与姿态级 ratio 对应不同干预，不应解释为相同物理遮挡强度；人工图像遮挡也不能替代自然遮挡或运动模糊实验。

证据：[图像遮挡结果表](../paper/ivc_draft_20260821/tables/image_occlusion_summary.tex)、[图像与姿态干预对比图](../paper/ivc_draft_20260821/figures/extension/image_occlusion_robustness.pdf)。

## 4. E1 的解释由哪些适配实验支撑

E8 已经包含以下验证，可用于回应 E1 的“需要更多解释”：

- 对 VideoPose3D、PoseFormer、MotionBERT 分别训练 heads-only 和 full adaptation，共 6 个模型。
- 另训练一个混合四种前端的 mixed/full 模型。
- 加上原冻结模型，在四种前端上组成 8×4=32 个评估条件，同时检查目标前端恢复和 SAM3D 性能保持。
- 三种前端 full adaptation 相对各自冻结模型的 MPJPE 降幅为 57.5%、48.9%、45.4%。这些百分比以适配前误差为分母，不是相对 canonical averaging 的融合增益。
- mixed/full 的 SAM3D 误差由 0.1551 增至 0.1809，增加 16.7%。

这些结果支持“前端分布失配可以通过适配缓解”，但不能单独证明负迁移只有一个原因，也不能声称同一个模型在所有前端上都无代价地提高性能。

证据：[适配结果矩阵](../paper/ivc_draft_20260821/tables/frontend_adaptation.tex)、[现稿解释](../paper/ivc_draft_20260821/sections/p1_results.tex)。
