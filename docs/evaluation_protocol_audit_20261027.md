# 评价协议核查与 chen_4 手持录像实验记录（2026-10-27）

## 1. 发现：规范化参考帧按 batch 取，不按样本取

`dual2pose/trainer/canonicalize.py::canonicalize_pose_torch` 对 (B, T, J, 3) 输入先 reshape 成 (B·T, J, 3)，`mode="first_frame"` 取 `pelvis[0]`、`R[0]`，即整个 batch 第 1 个样本的第 1 帧作为全部样本的参考。训练与评价都用这个函数，左路、右路、GT 各自取各自 batch 的第 1 个样本，三个坐标系互不相同。

后果：规范空间的误差随 batch 大小变化，模型学会抵消这个偏移，评价时表现为大幅"增益"。

| Unity 全部 64,440 条测试，common-13 | 规范平均 MPJPE / PA | CanonFuse3D | 仅门控 |
|---|---|---|---|
| batch 256 共用参考（论文表 2，已逐数复现） | 0.2792 / 0.1162 | 0.1551 / 0.0637 | 0.2050 |
| batch 4096 共用参考（训练设置） | 0.4161 / 0.1183 | 0.1852 / 0.0756 | 0.3805 |
| 逐样本参考 | 0.1257 / 0.0673 | 0.1295 / 0.0604 | 0.1247 |
| 逐样本参考，平均 + 训练集常数关节偏移 | 0.1484 / 0.0609 | | |

逐样本参考下 Unity 没有融合增益：MPJPE 持平，PA 的 10% 优势等于一个用训练集估计的常数骨架偏移（SAM3D 骨架到 Unity 骨骼，平均 0.085）。

| Ski-PTZ-Pose 30 条测试，common-13 | 规范平均 | 平均 + 训练集常数偏移 | CanonFuse3D | 仅门控 |
|---|---|---|---|---|
| batch 4（论文） | 0.3487 | | 0.1794 | |
| 逐样本参考 | 0.2852 / PA 0.1877 | 0.2523 / 0.1776 | 0.1663 / 0.1170 | 0.2828 |

Ski-PTZ 的增益在逐样本参考下保留（−42%），常数偏移只解释 0.033，是真实的域内增益。

受影响的结果：所有在规范空间、batch > 1 下算出的数（主表规范空间部分、门控消融、视角分层、时间偏移、采样率、遮罩、图像遮挡、前端泛化与适配、多视角、C07）。不受影响：PA-MPJPE、表 3 原生输出比较。

正确做法：参考帧按样本取（每个 b 用自己的首帧）；相机自身运动时用逐帧人体坐标系（`mode="per_frame"`）；建议主表报告按样本 MPJPE、按帧 MPJPE、PA-MPJPE 三列。训练也需用修正后的规范化重训。**截至本记录，benchmark 代码与数据未改动。**

核查脚本与结果（任务临时目录，可能已清理）：`unity_batchref_check.py`、`unity_batchref_full.py/json`、`unity_batchref_B.py`、`unity_bias_corrected.py/json`、`ski_bias_corrected.py/json`、`pocket3_cv_adapt_strata.py/json`。

## 2. chen_4 手持双 Pocket 3 录像

数据：`skiing/data/skiing_pocket3_20261012/`，chen_4，两台手持 DJI Osmo Pocket 3，48 s，视频 GT 由 8 台外部相机三角化（COCO-17）。
流程：`SAM3Dbody/main_video.py`（逐帧 SAM3D）→ `dual2pose/eval/eval_pocket3.py`（评价）→ `dual2pose/eval/adapt_pocket3.py`（20 轮适配）→ `dual2pose/eval/train_pocket3.py`（正式训练）。协议：UTC 配对；排除检测高度 < 35% 画面的帧（对时手机段）；COCO-17 映射到模型骨架，颈部取肩中点；窗口首帧锚点需可靠；按帧人体坐标系为主指标。

## 3. 结论

方法的增益来自残差头在训练域内学到的修正（Ski-PTZ −42%，chen_4 域内训练 −10% 到 −13%）；门控在所有数据上接近 0.5；冻结权重跨域不迁移；Unity 主表的 44.5% 是协议产物。论文主张应改为"域内训练下有效"，主基准需按逐样本参考重算（并考虑重训）后再投稿。
