## 选模规则的含义与固定方案

“选模”指在训练保存的多个epoch/checkpoint中，确定最终测试所用的一份权重，不是选择网络架构，也不是重新划分数据。

| 训练任务 | 选模规则 |
|---|---|
| Unity主模型、本地监督基线和门控消融 | 根据独立val的直接common-13 MPJPE选最低者；test不参与 |
| Ski | 保持论文的固定预算、预先指定checkpoint原则；不把复用train的监控值称为独立val。新100轮任务默认固定最终epoch99，不能事后用test选epoch；具体方法预算另有声明时按其预定最终轮次 |
| 前端适配 | 使用Unity val的直接common-13 MPJPE |
| Pocket3正式域内训练 | 时间划分的val选最低直接common-13 MPJPE；同一选定权重一次产生test主指标与辅助指标 |
| Pocket3固定20轮补充适配 | 按原论文固定预算输出最终权重，不用test挑epoch；与正式验证选模的训练实验分别标注 |
| MetaPose / DeciWatch / STRIDE | 保留论文声明的方法专属训练目标、预算和选模契约；不是所有外部方法都具有可互换的监督loss。最终测试共同使用per-frame/common-13直接MPJPE，PA仅辅助 |

数据划分决定哪些样本属于train/val/test；选模规则决定使用哪个训练时刻的权重。两者需要记录，但不是同一件事。

## 结论与计数口径

保留现稿主文和补充材料全部学习实验，保守预算为 **36 次训练/适配**，另有 **2 套 STRIDE 测试时优化**及下述冻结评测矩阵。36 次不是36个满规模100轮训练，也不是36个GPU日。

全部方法必须通过新协议接入检查。MetaPose暂按不变原生预测经合法逐帧变换重评分计费；若接入检查表明必须改变其训练输入契约，则两数据集重训使总数增至38次。不能为了维持36这个预算而给某个方法保留旧评价协议。

- 基准、消融、前端适配：20次。
- Pocket3 正式域内训练：12次。
- 补充材料 Pocket3 20轮适配：4次。
- 若将主实验 Unity full 与消融 full 的种子、初始化、精度、优化器、调度器、训练数据顺序及选模规则全部统一，full可共用，减为35次；当前两入口的调度器等设置不同，不能直接扣掉。
- 若删除补充材料的20轮适配论述，可减4次；这属于缩减稿件范围，不是复用旧数字。
- 主文及all-15补充表里的普通 cross-view MLP 行已注释，不计入。若恢复该行，另加两数据集共2次训练。
- 原有“2 folds × 3 seeds”的主基准矩阵已经退出投稿范围，不自动加入这6次训练。除Pocket3外，按现稿单种子、固定划分统计；不能由此声称多种子稳健性。

## 必须先固定的协议与代码准备

1. 模型输入及GT各自逐帧建立身体坐标系，保留尺度；模型输出直接与规范GT评分，不在主指标前再次规范化、定根或拟合GT。
2. 主指标、验证选模、全部受控实验统一common-13；PA和all-15仅作为明确标注的辅助结果。训练loss保留既定native骨架，除非另行批准修改研究设计。
3. 原生输出方法需要预先声明从其输出坐标系到评价坐标系的映射。不能对所有模型输出盲目再调用canonicalize；例如MetaPose可沿用输入左视角定义的逐帧变换，不能用GT拟合主指标。
4. Ski保持论文数据划分，不再规划新增验证划分。将执行代码接回论文已经声明的预定checkpoint规则：训练集监控可以保留，但不能借用`val/mpjpe`名称把它当成独立验证来选模。测试集合与论文一致，除有据可查的无数据条目外不得改变覆盖。
5. Pocket3监督loss需接入GT可靠性掩码；统一训练/验证/测试有效点策略。新逐帧GT要求每帧锚点可靠，旧稿仅要求窗口首帧，需重新生成窗口与分块manifest；37全窗、18测试窗、540帧对均不能直接继承。验证和测试无有效点或空窗口必须报错。
6. Pocket3接入主流程的数据适配层：输入、GT映射到对应模型的native骨架；规范化参数来自统一协议与checkpoint的骨架索引，不再有Pocket专用首帧/输出再规范化路径。当前入口拒绝Ski的13点checkpoint，需补充合法13/15映射并核对face-sign与左右手系。比较方法共享同一最终身体轴定义；不能通过假眼部点或改checkpoint标签绕过不兼容检查。
7. 迁移全部论文入口：`main_baseline_data.canonical_batch`、`run_deciwatch.py`、`evaluate_metapose.py`等显式first_frame调用，以及依赖它们的门控消融、C07、STRIDE、图表生成和原生输出比较。当前论文任务清单不得调用历史协议路径；历史复现单独隔离。不能只把输出JSON的协议标签改成per_frame。
8. 前端适配调度器仍默认旧Unity权重与旧输出目录，须替换为新的per-frame checkpoint及新目录。所有学习方法的缓存必须区分raw与canonical，后者需重新生成。
9. 同步估计器的身体坐标descriptor也迁移到per-frame，并重新在Unity validation标定置信阈值；保留原偏移搜索范围和中央20帧评分范围，更新方法说明。
10. 运行前固定代码版本/补丁hash、配置、种子、索引、关节表、坐标系和单位；输入/GT规范化应通过batch大小和排列不变性测试，输出平移必须仍计入主MPJPE。

## 所有方法的统一接入要求

| 方法 | per-frame接入方式 | 是否新增训练预算 |
|---|---|---|
| 左/右单视角、canonical average、aligned average、3D quality weighting | 共享逐帧输入规范化；输入间的相似变换属于方法本身，禁止用GT拟合；输出直接评分 | 无 |
| Proposed、TCN、SmoothNet、门控消融、前端适配 | 训练输入与GT均采用新逐帧表示，预测后直接监督/评分 | 已计入36次 |
| DeciWatch | 新逐帧canonical average及GT，保留四观测帧恢复任务，重训并直接评分 | 已计入2次 |
| STRIDE | 新逐帧canonical average逐窗TTA，不用测试GT优化；输出直接评分 | 单列2套TTA |
| DLT / reprojection-gated DLT | 保留原生像素与标定中的三角化计算；将结果作为3D姿态来源一次映射到声明的逐帧身体表示，再进入共同评分。逐帧不意味着把像素坐标或相机矩阵直接当身体坐标 | 无 |
| DLT-residual | 从逐帧表示的DLT姿态与既定几何特征预测残差，输出直接与规范GT比较 | 已计入2次 |
| MetaPose | 保持2D重投影方法语义；原生结果通过预先规定的输入侧逐帧坐标变换映射后直接评分，不按预测误差重新拟合。仅在输入/监督本身不变且通过坐标变换验证时复用权重/原生预测 | 默认无额外训练；若验证表明必须改变训练输入契约，另加2次，明确标注adaptation |
| N-view、时间扰动、遮挡及C07 | 相同checkpoint、逐帧变换和common13 scorer，按固定cohort出全矩阵 | 无额外模型训练 |
| Pocket3冻结/训练/适配 | 数据适配后调用同一前向、loss、scorer和checkpoint导出；per-frame直接MPJPE为唯一主指标 | 已计入12+4次 |

所有方法统一的是身体坐标表示、评价关节及主指标契约，不是取消外部方法原有输入要求或把所有方法改成同一个模型。原生几何方法的坐标转换必须写清楚：它与对已经输出规范坐标的学习模型再次拟合/规范化不同。

Pocket3的具体验收要求：先冻结时间分块，再在块内构建窗口；任何训练窗不得跨val/test边界；训练只用train，选模只用val，test不选权重；所有方法使用相同有效点/窗口、单位和GT；GT可靠性mask用于loss/评分且不作为预测特征；正常输出直接评分，PA/再次规范化只进入明确的辅助诊断列。域内微调学习率、最大轮数与早停预算保留论文设置并显式记录，主流程统一不要求不同数据集学习率相同。

## 推荐顺序与停止条件

1. **P0：全方法协议接入。** 保持Ski论文数据划分并落实其预定checkpoint原则；迁移全部基线/评测入口与同步descriptor；完成Pocket主流程接入、mask/骨架映射/分块窗口manifest。逐方法执行小批次训练或推理-保存-加载-评分闭环及坐标/batch不变性测试，核验raw缓存。当前任务注册表中的所有方法通过后再正式训练。
2. **P1：两个主模型。** Unity/Ski各重训一次，并产出所有无训练基线及MPJPE/PA/Accel。先确认没有数据/坐标错误；结果不优于基线也照实记录，不以测试收益决定挑checkpoint。
3. **P2：核心比较与机制。** 补6个本地学习基线、2个DeciWatch、3个门控消融，及MetaPose重评测、STRIDE两套TTA。累计13次训练，可判断主要贡献是否仍受支持。
4. **P3：部署与前端适配。** 增加12次Pocket正式训练、7次前端适配、4次Pocket补充适配，累计36次。只依赖已冻结的主模型，不用后续测试结果倒调主模型。
5. **P4：完整冻结研究。** 45/18遮挡、C07、7+7时间扰动、6角度箱、33同步格、N-view等可在主模型冻结后穿插调度；同一GPU上的计时实验单独运行，避免并发干扰。
6. **P5：论文更新与验证。** 同步主文方法/协议、结果表图、补充材料及摘要/讨论/结论。Access `main.tex` 是唯一正文真源，不能运行转换脚本覆盖它；先保存快照再手工合入。数据源表可能只需更新Pocket样本数；其余10张主文结果表均需重构或复核，旧native比较表不再作为当前实验的协议例外。
