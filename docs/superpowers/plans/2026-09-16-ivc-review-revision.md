## Task 3：C06 门控诊断与受控消融

**已核对实现：** `dual2pose/models/crossview_fusion.py` 返回 `aux["alpha"]`。融合为 `alpha * base_l + (1-alpha) * base_r + residual`；两个 base 都包含对齐后的另一视角。因此 alpha=1/0 表示选左/右候选，不等于只使用一个原始视角。现有 `disable_residual` 只清零输入差分特征，**不会关闭输出 `residual_head`**。

**Files:** 后续涉及上述模型、`dual2pose/trainer/train_crossview_fusion.py`、新增 `dual2pose/eval/evaluate_gate_interventions.py` 和 `tests/test_gate_interventions.py`。新增开关保持默认路径与旧 checkpoint 兼容，不重定义旧开关。

- [ ] 固定原评估索引、batch 划分、checkpoint、归一化和关节映射；保存文件哈希。先在验证集检查导出能否重建默认输出，再处理测试集。

- [ ] 复用现有单侧严重损坏和左右互换条件；新增预先固定的“前半窗口左侧损坏、后半右侧损坏”及反向条件。不能依据测试结果挑选有利窗口；示例按固定 ID 抽取，另报告全索引汇总。
