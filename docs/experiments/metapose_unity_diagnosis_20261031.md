# MetaPose Unity：Pegasus 重训精度变化诊断（2026-10-31）

## 结论与本次处理范围

Pegasus 的 MetaPose Unity 任务已完成训练、验证集选模、完整预测导出和评分。此次检查没有发现把错误数据、坐标转换或评分协议带入迁移后实验的证据。最强的异常证据出现在学习得到的深度方向：在同一 CPU 环境、同一批训练/验证输入上，新权重从第一阶段开始就与输入预测的中心化 Z 坐标负相关，原权重则保持正相关；X/Y 拟合和整体骨架半径均正常。

这一结果支持“2D 监督下学习到了不同且更不符合输入深度的 3D 解”作为当前最有证据的解释。它不证明每帧都发生了纯 Z 反射，也不能单凭相对于输入预测的相关性判定真实深度的正确性。实际精度下降由既有独立测试评分确认；本次新增诊断没有读取测试数组或 GT3D。

本次用户范围是诊断并重跑失败任务。**保留已成功完成的 MetaPose 结果与其来源，不将精度较差改标为执行失败，不自动替换权重、翻转深度或改训练配方。** 稳定训练只能作为另行明确范围的实验候选；本次不启动这类调参或重训，不修改论文。

## 训练与选模审计

两次训练均为 seed 42、3 阶段 × 10 epochs、batch 1024、float64、同一官方源码 commit、同一网络结构；训练、验证和测试 prepared manifest 完全一致。选中的帧索引摘要也一致。训练用 uncertainty 的权重最大差为 `2.89e-15`，方差最大差为 `5.55e-16`。

| 阶段 | 原选中 epoch | 原完整验证 2D MSE | 新选中 epoch | 新完整验证 2D MSE |
|---|---:|---:|---:|---:|
| 1 | 9 | 0.002645573 | 5 | 0.002654821 |
| 2 | 10 | 0.002954804 | 8 | 0.002763790 |
| 3 | 5 | 0.002980100 | 6 | 0.002745941 |

两次均正确选择各阶段完整验证集 2D MSE 最小的 checkpoint，文件摘要与记录对应。新最终验证 2D MSE 下降约 7.86%，因此不能将测试 3D 下降解释为选错 checkpoint，或简单称作 2D 拟合没有收敛。

旧历史曾出现阶段 2 多个 epoch 的验证 2D MSE 从约 0.003 升至约 0.073，之后恢复；最终选中的权重没有这种损失水平。新训练也存在损失波动，但新最终选模没有出现相同幅度的验证损失崩溃。

运行环境的 Python 从 3.11.15 变为 3.11.14；记录的 pip 包列表一致，包括 TensorFlow 2.15.1、Keras 2.15.0、NumPy 1.26.4。Unity 没有开启 TF deterministic operations。当前 wrapper 为 Ski 增加了可选 identity 初始化与 clipping，但 Unity 默认仍为 random residual heads、Adam 1e-4、不裁剪；实际额外执行的是梯度范数统计和有限值检查。

保存的 train/val 初始化状态并非逐位相同：固定样本中最大状态差约 `2.10e-4`，集中在 pose/rotation，scale/shift 相同。这说明训练数值路径发生变化，不能只凭 seed 相同期待相同权重。硬件、浮点初始化和新增统计图各自对最终差异的贡献尚未通过单变量复现实验分离，不能断言某个设备或某行统计代码就是根因。

## 固定训练/验证输入的几何对照

新增探针固定使用训练集和验证集各 128 个均匀间隔帧条目。它只读取 `xyz/uv/labels2d`，在同一个 CPU 运行环境重新初始化，并逐阶段加载两次运行已经选定的权重。S1 是未学习的初始解，阶段 1–3 是对应的已选 learned solver 前缀。没有依据该探针重新选模。

相关性定义：各投影姿态和输入姿态分别减去自身关节均值，然后对样本、两视图、关节汇总计算每个轴的归一化内积。它是相对于输入预测的中心化坐标相关性，不是 GT3D 准确度，也不是“反射帧占比”。

| 阶段 | 原 Z 相关性 train / val | 新 Z 相关性 train / val |
|---|---:|---:|
| S1 | +0.9830 / +0.9851 | +0.9830 / +0.9851 |
| 1 | +0.3654 / +0.2111 | −0.2993 / −0.2428 |
| 2 | +0.3655 / +0.2073 | −0.2954 / −0.2341 |
| 3 | +0.3775 / +0.2210 | −0.2957 / −0.2374 |

新最终阶段 train 的 X/Y 相关性为 0.9727/0.9851，val 为 0.9545/0.9812，和旧运行接近；改变集中在深度方向。最终 Z 与输入的中心化 RMSE，train 从 0.2614 增至 0.3700，val 从 0.2890 增至 0.3567，均为归一化坐标单位。

两次所有检查阶段均通过现有 broad geometry gate：异常半径帧比例为 0，最终投影/input 半径中位数约 1.04，camera scale 有限且为正。因此这里不是此前 Ski 的整体骨架半径塌缩；只检查有限值、半径和 scale 不能检测这种深度方向差异。新模型的 Z 分布标准差也与原模型接近，没有压成零深度。

2D 损失只观察弱投影的 X/Y，同时模型可以修改姿态和相机状态。现有目标没有直接监督深度或强制保留输入深度方向。上述“相似 X/Y 和半径、不同 Z 方向、较低验证 2D 损失”的组合，与该监督下的深度歧义相符。原运行本身的最终 Z 相关性也远低于 S1，不能据此称原模型已经解决了这一问题。
