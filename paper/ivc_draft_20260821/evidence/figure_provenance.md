# Figure provenance

## Journal-specific figures

- Since 2026-09-18, `main.tex` includes `figures/journal/study_overview_visio.pdf` (Fig. 1) and `figures/journal/method_pipeline_visio.pdf` (Fig. 2). Both are converted from the author-drawn Microsoft Visio exports `CanonFuse3D_Formula_Final_A01.svg` and `CanonFuse3D_Formula_Final_A02.svg` in the same directory: rendered to vector PDF with headless Chromium (print-to-pdf at the SVG canvas size of 22 in), embedded raster images downsampled to 200 ppi on that canvas with Ghostscript (about 800 dpi at the printed width), and cropped to the drawn content with a 6 pt margin. Text remains vector; fonts are embedded (Liberation Serif substitutes for Times New Roman). The photographs and skeletons inside both figures come from the author-collected outdoor recording `pro_1`, frame 746, and are qualitative only. The earlier matplotlib-generated `study_overview.pdf` and `method_pipeline.pdf` remain in the directory and are still produced by `scripts/generate_journal_figures.py`, but are no longer included by `main.tex`.

- `figures/journal/study_overview.pdf` is generated by `scripts/generate_journal_figures.py` from the method and evaluation scope stated in `main.tex`. It is a conceptual overview and contains no quantitative result.
- `figures/journal/method_pipeline.pdf` is generated by the same script from the executable CanonFuse3D stages documented in the Methods section. It identifies the first frame of the first sequence as the stream-specific minibatch anchor, distinguishes this batch-referenced transform from sequence-level pose alignment, and does not depict camera calibration.
- `figures/journal/dataset_examples.pdf` and `dataset_examples.png` are generated by the same script as a synchronized two-view by three-source montage. Unity uses `Anim_Female_Skier_Skiing`, frame 36, views `capture_L3_A000` and `capture_L3_A210`; Ski-PTZ-Pose uses `seq_412`, frame 75, cameras 02 and 03; the author-collected source uses `run_3`, frame 0, left and right views embedded in the SAM3D result archives. The Unity foreground is deterministically cropped to a 16:9 panel for legibility; the other four frames retain their original field of view. The author-collected panels are qualitative only. Rendered artifact hashes are PDF `64a822f55ce6a35cc33980542823236fe114826a0796decc864bac15bc142b4d` and PNG `eb576e9d2ef3786f07ee8c6c149be408919ce2a752300ce9c99037d5f5a62034`.
- `figures/journal/realworld_qualitative.pdf` is the archived, superseded recomposition of two MMSports qualitative outputs; it is no longer included in the main manuscript.
- `figures/journal/realworld_qualitative_refresh.pdf` is newly inferred and drawn by `scripts/generate_realworld_refresh.py`. It uses previously unshown clips `pro_2` (shared-frame midpoint 1231, window 1216--1245) and `run_4` (midpoint 180, window 165--194), fixed before inference. Both use the archived Unity-trained checkpoint, CPU inference, and batch size 1. RGB images retain their full fields of view; pose panels use the actual 13 body joints with no synthetic head and a single global display scale/view. The checkpoint, all 120 source NPZ files, selected windows, saved predictions, and output hash are recorded in `evidence/layout_revision_20260917/realworld_refresh_manifest.json`. No ground truth or accuracy ranking is inferred from these qualitative panels.

## Quantitative extension figures

- The new calibration sensitivity figure, figures/extension/c07_calibration_sensitivity.pdf, is generated by scripts/generate_c07_calibration_figure.py directly from the seven archived C07 JSON files. All 35 values match the former main table, now Supplementary Table S16. Seven panels share axes and show all measured angles (0/1/3 degrees); unchanged pose-only references are horizontal lines. Lines do not imply observations at intermediate angles. Source/figure/script hashes and the claim trace are recorded in evidence/compact_layout_20260917/calibration_figure_manifest.json.


- `temporal_sampling.pdf`, `view_angle.pdf`, and `masking_robustness.pdf` are generated by `scripts/generate_extension_artifacts.py` from the CSV artifacts whose SHA-256 values are recorded in `evidence_manifest.md`.
- `nview_scaling.pdf`, `temporal_alignment.pdf`, and `frontend_adaptation.pdf` are generated by their corresponding `generate_p1_*_artifacts.py` scripts from validated summary matrices under `logs/ivc_p1/`.
- `tables/nview_efficiency.tex` is generated by `scripts/generate_p1_nview_artifacts.py` from the validated `logs/ivc_p1/nview/nview_efficiency.csv`; it reports synchronized serial latency and the MPJPE--cost trade-off for the same 44 accepted camera groups.
- `image_occlusion_robustness.pdf` and `tables/image_occlusion_summary.tex` are generated by `dual2pose/eval/render_e4_e5_artifacts.py` from the packaged E5 image/pose comparison and complete 18-cell summary. The table retains all negative gains; the figure plots fused MPJPE only, so baseline-gain claims refer to the table. Ratios match protocol labels, not physical occlusion severity.
- All eleven journal figures use `scripts/journal_figure_style.py`. Color is paired with marker shape, line style, direct labels, or cell values so that interpretation does not depend on color alone.

The original MMSports figure files remain archived under `figures/original/` as source and provenance artifacts, but `main.tex` no longer includes them directly.
