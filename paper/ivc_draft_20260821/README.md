# IVC manuscript package

Elsevier-style journal manuscript for Image and Vision Computing, extending the accepted MMSports 2026 preliminary paper. Directory cleaned on 2026-09-18: only files needed to compile, submit, or reproduce the manuscript remain here. Superseded drafts, marked-up diffs, unused figures and tables, and working notes were moved to `../ivc_draft_20260821_archive_20260918/`.

## Compile

Run from this directory; the supplement must be compiled first so that the main text can resolve its `S-` cross-references.

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error supplementary.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

## Layout

| Path | Role |
|---|---|
| `main.tex`, `main.pdf`, `main.bbl` | Journal manuscript (42 pages) |
| `supplementary.tex`, `supplementary.pdf`, `supplementary.bbl` | Supplementary material (26 pages), referenced from the main text via `xr-hyper` |
| `references.bib` | Shared bibliography |
| `sections/` | Text blocks included by `main.tex` and `supplementary.tex` (`p1_results.tex`, `c07_results.tex`, `c07_supplement.tex`) |
| `tables/` | Generated LaTeX tables included by the two documents |
| `figures/journal/` | Fig. 1 and Fig. 2 (`*_visio.pdf`, converted from the Visio sources `CanonFuse3D_Formula_Final_A01.svg` / `A02.svg`), dataset examples, occlusion examples, gate diagnostics, and the real-world qualitative figure |
| `figures/extension/` | Quantitative figures generated from the evidence CSVs |
| `scripts/` | Figure and table generators used by the repository tests (`tests/test_ivc_*.py`, `tests/test_p1_*.py`) |
| `evidence/` | Result snapshots, hashes, and provenance records behind every reported number |
| `cover_letter.md` | Cover letter with the conference-overlap disclosure; MMSports DOI still to be added |
| `Highlights.txt` | Highlights for separate upload (3-5 bullets, at most 85 characters each) |
| `graphical_abstract.pdf`, `graphical_abstract.png` | Mandatory graphical abstract, 13 x 5 cm (1535 x 590 px at 300 dpi; Elsevier minimum 1328 x 531), built by `scripts/generate_graphical_abstract.py` from the Fig. 1 skeleton panels |
| `suggested_reviewers.md` | Five suggested reviewers with institutional e-mails and the conflict-check record |
| `author_confirmation_checklist.md` | Full pre-submission checklist, including items that need every author's input |
| `coauthor_confirmation_request.md` | Ready-to-send message (Japanese, with the manuscript's English statements quoted) asking the co-authors to confirm affiliations, declarations, CRediT roles, data/ethics statements, and the AI declaration |
| `revision_log.md` | Chronological record of manuscript changes |

## Regenerating figures and tables

Run from the repository root:

```bash
python3 -m paper.ivc_draft_20260821.scripts.generate_journal_figures
python3 -m paper.ivc_draft_20260821.scripts.generate_extension_artifacts
python3 -m paper.ivc_draft_20260821.scripts.generate_p1_nview_artifacts
python3 -m paper.ivc_draft_20260821.scripts.generate_p1_temporal_alignment_artifacts
python3 -m paper.ivc_draft_20260821.scripts.generate_p1_frontend_adaptation_artifacts
python3 paper/ivc_draft_20260821/scripts/generate_consolidated_artifacts.py
python3 -m paper.ivc_draft_20260821.scripts.generate_graphical_abstract
```

Fig. 1 and Fig. 2 are not produced by these scripts. To refresh them after editing the Visio sources, export SVG from Visio, print the SVG to PDF with headless Chromium at the 22-inch canvas size, downsample embedded raster content with Ghostscript, and crop to content (see `evidence/figure_provenance.md`). The legacy matplotlib versions of these two figures are still generated by `generate_journal_figures.py` but are no longer included.

The generated main-comparison tables (`native_reference.tex`, `native_reference_all15.tex`, `native_output_comparison.tex`) come from `dual2pose.eval.render_main_baseline_tables` and the native-output export; see `evidence/main_baselines_manifest.json` and `evidence/results/`.
