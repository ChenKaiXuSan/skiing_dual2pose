# IVC 两张流程图：绘图交接素材包

这份素材用于交给绘图者重新排版、绘制论文图。图一讲清输入、处理和输出；图二展开五路特征和融合机制。所有说明以 2026-09-17 工作区中的 IVC 稿件与代码为准，原稿未改动。

## 三数据集扩展版（新增）

已增加 Unity、Ski-PTZ-Pose、自采双视角视频各 4 组，共 12 组样本。**现在先打开 `ASSET_GALLERY.html` 选样，再看 `MULTI_SAMPLE_INDEX.md`（另有 Word/PDF）**。每组的 SVG/PDF/PNG 和数值文件位于 `multi_samples/数据集/编号/`。新样本由现有固定检查点在 CPU 上推理，包含真实门控与多头平均注意力热图。

Unity 使用 avatar GT；Ski 只标 constructed reference，使用 13 个共同关节；自采样本无 GT，不给精度改善结论。自采统一使用 Unity 检查点。十二组先按动作、视角和片段中间位置选定，不按模型效果筛选。

原版单样本素材仍在根目录 `assets/`、`data/`；原图册另存为 `ASSET_GALLERY_SINGLE.html`。下面的固定 sample 0、frame 10、20 项素材等说明只适用于原版；新增样本的帧号和来源以多样本索引为准。

## 原版绘图任务书

1. `DRAWING_BRIEF.docx`：可转发的中文绘图任务书，含布局、英文标注、公式、注意事项。
2. `ASSET_GALLERY.html`：离线素材图册，逐项预览所有素材，并标明真实数据或机制示意。

也保留了 `DRAWING_BRIEF.md` 和 `captions_and_formulas.tex`，方便复制文字和公式。

## 文件怎么用

| 位置 | 内容 | 使用方式 |
|---|---|---|
| `assets/*.svg` | 可编辑矢量骨架、特征小图、真实热图 | 首选，导入 Illustrator、Inkscape、Figma 等后重排 |
| `assets/*.pdf` | 对应矢量 PDF | 备用导入或检查 |
| `assets/*.png` | 300 dpi 透明背景预览；另有两张未修改 RGB 原图 | 快速拼版，RGB 可等比例裁切 |
| `data/poses.csv` | 同一示例的各阶段三维坐标 | 绘图者需要重投影或调整相机时使用 |
| `data/gate_alpha.csv` | 30 × 15 真实门控矩阵 | 重画热图时保留原值及 0–1 色标 |
| `data/local_errors.csv` | 固定帧每关节对照误差 | 选择局部放大位置之前核对 |
| `data/provenance.json` | 样本、帧号、来源、校验记录 | 由作者留存；核查用 |
| `reference/` | 当前论文的三张相关原图 PDF | 只参考信息层级，不要求照抄版式 |

## 已准备好的真实素材

双视角 RGB、原始 3D 输入、对齐前后骨架、五路特征中的姿态/差值/速度/旋转、两个基础候选、门控热图、输出残差、融合结果与 Unity GT 对照，均来自同一个固定样本。唯独 `attention_connections` 的跨关节连线为机制示意，不代表实测注意力权重。

样本是 Unity test index 0，female / Anim_Female_Skier_From_Skiing_To_Straight，视角 A000 与 A010；主展示帧为窗口第 15 个位置，对应原始 frame 000010。人体坐标轴素材使用同一样本的首帧锚点，时间小图使用相邻窗口位置。该视角对相差 10°，不能把它标成大视差或宽视角示例。

规范化骨架素材采用统一斜投影；原始相机坐标的骨架另翻转显示纵轴，使人物直立。这些都是三维数据的展示投影，便于插图使用，**不是 RGB 相机的投影**。因此不要把这些骨架直接叠加到 RGB 人物上；现有材料适合“RGB 小窗 + 并列 3D 骨架”。如需要严格像素对齐的叠加图，需要另行导出该帧的 2D 关键点或相机投影。

输出由已归档的门控、候选骨架和输出残差按公式复原；本次没有重新训练或重新运行模型推理。对齐候选经 CPU 重算后与归档值最大差异为 4.77e-7。示例的真实门控范围约 0.459–0.597，热图采用固定 0–1 色标。单帧全 15 关节平均误差为 canonical average 0.09211、融合 0.04920（canonical coordinate units）；这是局部示例，不能代替论文总体指标。

## 给绘图者的一句话

请按任务书重画两张英文论文图：图一保留五步总览，在输入、对齐和输出处嵌入素材；图二突出五个 3D 特征拼接、双向跨视角注意力、时间细化，以及真实门控热图与残差公式。SVG 可编辑，文字可缩短，数据含义与箭头关系请保持任务书定义。
